### 補足動向（Web・規約情報）
- **FANZA同人**: 「AI」「一部AI」ラベル。各種一覧・ランキングから除外されAIフロア中心。月3作品上限（報道）。
- **DLsite**: AI生成作品は専用フロア、申告必須（AI生成/一部利用）。月3作品申請上限（申請日基準）。画像上限500枚程度。
- **価格・売上傾向**: CG集中央値DLは低め（数十〜数百）。500〜999円帯がボリューム。上位は数千〜万本。ゲームは単価高く競争少ない傾向。
- **ツール・手法**: ComfyUIでモーション転送（静止画に動き移植）、Stable Diffusion + ADetailer/Forge。動画生成でストーリーアニメーションがランキングに影響し始め。

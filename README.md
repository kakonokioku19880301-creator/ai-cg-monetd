### X投稿抽出・要約（同人×AI作品の販売・収益化）

**1. 賢木イオ (@studiomasakaki)**
- **タイトル/要点**: AIエロ漫画をFANZA＋DLsiteで累計約1500本販売。税込770円中、手数料後手取り約431円/本。実働7日・50ページで最終利益約50万円。
- **なぜ**: 具体的な販売数・単価・手取り・制作規模の実例。低ボリュームでも収益化可能だが、手数料40%前後を考慮した価格設定が重要。

**2. ボスねこ (@knyan151)**
- **タイトル/要点**: AIキャラ画像を数百枚まとめてCG集としてFANZAで販売。トップ層は1億超えプレイヤー。自身は700万以上売り上げ。セリフ付きや漫画化もOK。
- **なぜ**: シンプルな量産手法の具体例。市場の資産性（継続販売）を示し、0→1の入り口として実用的。

**3. WHITE TIGER (@hokutozenfactor)**
- **タイトル/要点**: 生成AI同人誌で月商30万円達成。量産より、売れた/売れなかった作品のデータを分析（クリック・タイトル・ジャンル・制作時間・手取り）し、次作に活かす。
- **なぜ**: データドリブンな改善プロセス。AIの制作速度を活かしつつ、無駄な量産を避ける実務的アドバイス。

**4. 井上純一 (@KEUMAYA)**
- **タイトル/要点**: FANZAがAI同人を隔離。大量出品で手書きが埋もれるため。DLsiteは既に対応済み。隔離によりAI同人の売上は半減〜1/10に急降下する可能性。
- **なぜ**: プラットフォーム規約・審査変更の影響を具体的に指摘。露出制限が売上に直結する重要ポイント。

**5. フーガ (@Fuga578)**
- **タイトル/要点**: 初のDL同人ゲーム（異世界エルフとの同棲生活）がDLsite「同人 ゲーム・動画ランキング (24時間)」にランクイン。
- **なぜ**: 同人ゲームのランキング実例。ゲーム形式でも初動で露出可能。AI活用のゲーム制作の可能性を示す。

**6. ヨーフ (@Yofu_ai)**
- **タイトル/要点**: FANZA同人で低クオリティCGではもう稼げない。参入者増とクオリティ上昇で、「ストーリー×高品質CG」で世界観を魅せる必要。自身はAI同人出版のみで月300万超え。
- **なぜ**: 市場の成熟と差別化の必要性。成功者の視点から品質・ストーリーの重要性を指摘。

**7. ツナマヨ (@business_tuna)**
- **タイトル/要点**: FANZA累計1000万＆売上ランキング1位達成。手順: 売れ筋確認→ジャンル・構図把握→サムネ共通点→作品数出す→「次も見たい」作る→続ける。脳筋パワープレイが正義。
- **なぜ**: 売れる売り方の具体的ステップ。タグ・サムネ・継続の実務的ノウハウ。

**8. バナーナ (@1banana2546)**
- **タイトル/要点**: AI作品大量出品でFANZA規制強化。低品質量産では参入しにくくなり、スキルある人にはチャンス。最高月収300万超。
- **なぜ**: 規制後の市場変化。品質重視へのシフトを示す。

### 補足動向（Web・規約情報）
- **FANZA同人**: 「AI」「一部AI」ラベル。各種一覧・ランキングから除外されAIフロア中心。月3作品上限（報道）。
- **DLsite**: AI生成作品は専用フロア、申告必須（AI生成/一部利用）。月3作品申請上限（申請日基準）。画像上限500枚程度。
- **価格・売上傾向**: CG集中央値DLは低め（数十〜数百）。500〜999円帯がボリューム。上位は数千〜万本。ゲームは単価高く競争少ない傾向。
- **ツール・手法**: ComfyUIでモーション転送（静止画に動き移植）、Stable Diffusion + ADetailer/Forge。動画生成でストーリーアニメーションがランキングに影響し始め。
